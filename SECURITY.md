# Security policy

## Supported versions

Security fixes are provided for the latest released version of
mosquitto-exporter.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/pauldeng/mosquitto-exporter/security/advisories/new).
Do not open a public issue before a fix is available. Include the affected
version, deployment conditions, impact, and reproduction details when possible.
